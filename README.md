## 🚀 Featured Projects

### 🌾 AI-Based Multi-Agent Farmer Query and Advisory System

> An intelligent advisory pipeline built on a coordinated multi-agent architecture, designed to interpret farmer queries in natural language and route them to specialized reasoning agents for crop, weather, and market-driven decision support.

- **Tech Stack:** `Python` · `Multi-Agent AI Framework` · `LLM Orchestration` · `NLP`
- **Key Impact:**
  - Designed a **modular agent-routing layer** that decomposes ambiguous natural-language queries into structured sub-tasks handled by domain-specific agents.
  - Reduced response irrelevance by structuring agent collaboration instead of relying on a single monolithic prompt — improving advisory **precision and contextual accuracy**.
  - Architected for **extensibility**, allowing new agents (e.g. pest detection, irrigation scheduling) to be added without re-engineering the core orchestration logic.

**[🔗 View Repository](https://github.com/praneethilluru)**

### 🚗 Web-Based Vehicle Risk Management System

> A full-stack risk assessment platform that processes vehicle and driver data to compute risk scores and surface actionable insights through a lightweight, server-rendered web interface.

- **Tech Stack:** `Python` · `Flask` · `SQLite` · `HTML/CSS` · `SQL`
- **Key Impact:**
  - Engineered a **normalized relational schema** to handle vehicle, driver, and incident data with efficient query patterns at scale.
  - Built a **risk-scoring engine** that processes structured data inputs and outputs categorized risk levels, replacing manual assessment workflows.
  - Delivered an end-to-end **CRUD-driven Flask backend** with clean route architecture, separating business logic from presentation for maintainability.
