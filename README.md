### 🧠 Engineering Philosophy

> *"Most people build software that works. I build software that's reasoned about — where every data structure choice, every query, and every agent decision has a justification behind it."*

I'm a backend-first engineer who treats **performance and intelligence as design requirements, not afterthoughts**. My work sits at the intersection of **systems programming** and **applied AI** — I don't just call an LLM API and ship it; I architect the orchestration layer around it. Whether it's optimizing a query path in SQL or decomposing a problem across cooperating AI agents, I care about *why* a system behaves the way it does, not just that it runs. I'm currently sharpening this craft as a B.Tech student, building production-style systems that solve problems people actually have — and preparing to bring that same rigor to a real engineering team.
